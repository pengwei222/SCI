# Independent results audit / 独立结果审计清单

本清单用于检查扩展实验能否支持论文中的精度、效率与泛化表述。它区分原始记录的一致性、独立数值验证，以及数学上的严格认证。入口为 `Run_Expanded_Benchmarks.ipynb`；不要求使用命令行。

## 1. 来源与完成度

- 核对 `FROZEN_PROTOCOL_SHA256.json`、各组 `manifest.json` 中的 7 个冻结源文件哈希及全部输入 NPZ 哈希。
- 每组必须有 `completion.json`，且 `sources_unchanged=true`。有完成标记但缺少汇总文件时仍不视为可交付的完整结果。
- 核对原始记录唯一键 `(case_id, method, tolerance, repeat)`；行数应为目标问题数 × 4 方法 × 容差数 × 重复次数，覆盖完整笛卡尔组合。
- 不混用旧 pilot 与正式版本；不把尚未完成的目录当作最终结果。

## 2. 数值有效性

- 直接检查用 Cholesky 求解 `A_i + w_i B_i`，不复用计时实现的谱白化公式；确认参考解、候选目标、梯度、协方差与融合均值的计算链分离。
- 参考分辨率需要 `verified=true` 且 `gap <= min(tolerance)/20`。单个优化器的 success/status 不能替代参考误差界。
- 候选成功需要同时满足求解器停止、目标误差上端、直接目标一致性、融合协方差/均值一致性、单纯形可行性，以及报告 bound 不小于已观测误差下端。
- 检查 NaN、Inf、负权重、异常退出、参考未解析与误差界违反；所有尝试保留。失败尝试的耗时不表示达到精度的时间。
- `verified` 是 float64 工程校验字段；直接 FW 下界加数值裕量不是向外舍入的区间认证。论文不得将其描述为 rigorous floating-point certification。
- 本次实现要求 `A_i` 正定、`B_i` 半正定。奇异 `A_i` 的理论结论与当前效率实验的实现范围分别说明。
- 在非唯一最优情形，目标与融合输出可一致而权重不同；不把权重差异直接记为失败。

## 3. 时间与统计

- 总时间包含新建模型、求解、所有证书尝试、回退，以及最终融合；排除文件 I/O 与独立参考审计。确认四种方法口径一致且单线程。
- 同一输入的重复计时先取中位数；随后按同一输入和容差形成“基线时间 / 新方法时间”，最后跨输入汇总。
- 配对速度统计只在双方成功时解释，并展示全部尝试数、有效配对数和失败数；不把失败静默丢弃。
- 每项计时统计核对有效值数与完整计时数。异常时保留的已耗时只能解释为尝试成本。
- Oracle 调用时间包含证书内部调用；不能再与证书时间相加。分别求中位数的阶段耗时通常不严格加成总时间中位数。
- P10/P90 等为跨输入的观测分位数，不是独立样本置信区间。若要推断不确定性，采样/重采样单位应与独立实验单位一致，并处理轨迹内相关性。

## 4. 外推范围与论文章节

| 证据 | 可支持的结论 | 不能直接推出的结论 |
|---|---|---|
| 7 个精度阈值的实测曲线 | 随目标容差收紧的运行时间与成功率变化 | 任意精度范围都具有相同趋势 |
| 尺寸、传感器数扫描 | 预先规定的规模范围内各实现的增长与配对收益 | 所有维度与所有分布的复杂度定理 |
| 内部、严格边界、非唯一、病态机制 | 不同最优权重几何下的数值行为 | 所有病态结构或全部退化问题的普适表现 |
| D4/D5 新增记录 | 对新增记录的迁移与稳定性 | 将同一记录的初始化/时间点当作独立轨迹证据 |
| 计算成本分解和消融 | 矩阵实现、候选生成、证书策略的具体贡献 | 单个机制在所有输入上必然加速 |

合成测试共有 240 组协方差输入、480 个目标问题；同一协方差的 trace/logdet 不是两组独立输入。3 次计时重复不是 3 个独立问题。D3 的不同初始化共享同一记录；轨迹时间点相关。引用样本量时应说明统计单位。

## 5. 交付前核对

1. 运行 notebook 的原始记录审计，逐项检查失败或参考未解析条目的 status。
2. 用配对原始表复核正文中的中位加速比、分位数、成功分母；避免用总体中位时间之比替代配对中位比值。
3. 绘图仅在完整计时结束后进行；保留 PDF/SVG、精确绘图 CSV 与来源 JSON。
4. 主文、图注、补充材料采用同一成功定义、时间口径与独立性表述；将数值验证和理论保证分开陈述。

本清单和 notebook 的静态审计不替代重复实测，也不将浮点一致性升级为数学认证。
